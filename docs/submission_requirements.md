## 1. MIT Sloan Sports Analytics Conference (SSAC 2027) — PRIMARY

**Rules page:** https://www.sloansportsconference.com/research-paper-competition
**Conference:** Feb 2027, Boston Convention & Exhibition Center.

### Two-stage process

| Stage | Deadline | Detail |
|---|---|---|
| **Abstract** | **Oct 1, 2026, 11:59pm EST** | Screened; a subset is invited to submit full papers |
| Full-paper invitations | late October 2026 | sent only to accepted abstracts |
| **Full paper** | **Dec 4, 2026, 11:59pm** | full manuscript |
| Finalists / posters announced | late January 2027 | best papers present; a separate set present as posters |
| Poster deadline | early February 2027 | if selected |
| Presentation deadline | mid-February 2027 | if selected |

### Abstract requirements (Oct 1)
- **Under 500 words**, including title and body.
- Required sections: **Introduction, Methods, Results, Conclusion**.
- May include **up to 2 figures or tables combined**.
- Submitted online.
- Judged on **novelty, academic rigor, reproducibility, application**.

### Full paper requirements (Dec 4)
- **Page limit:** approximately **6 pages main text + up to 3 pages appendix** (per recent editions;
  confirm the exact figure on the rules page when full-paper invitations go out).
- **PDF** submission.
- Referee-reviewed; best papers invited to present, others to a poster session.

### Mandatory for all submissions
- **Open-source repository link required:** a GitHub (or equivalent) link with the data used. Code is
  encouraged but optional. For any private/proprietary data, anonymize before sharing.
  → We already have this: `https://github.com/Henry1145141919810/CS2_Win_Probability_Model` (ensure it
  is clean and public before submitting).

### Track
- **"Other Sports"** (categories are Basketball, Baseball, Soccer, Football, Business of Sports, Other
  Sports). Esports / CS2 falls under Other Sports.

### Anonymization
- The rules page does not state a double-blind requirement, and a **public repo link is mandatory**, so
  submissions are effectively **not double-blind**. An arXiv preprint is therefore compatible.
  (Confirm on the rules page before submitting; if a blinded PDF is requested for the full-paper stage,
  prepare an anonymized manuscript then.)

## 2. arXiv — PREPRINT

**Submit:** https://info.arxiv.org/help/submit/index.html
**Format policy:** https://info.arxiv.org/help/policies/format_requirements.html
**TeX submission:** https://info.arxiv.org/help/submit_tex.html

- **Format:** (La)TeX / PDFLaTeX **preferred** (most stable); PDF accepted. **Do not** upload PS or a
  PDF generated from LaTeX source, or scans — these are rejected.
- **No page limit.** Post the full extended version here.
- **Size limit:** 50 MB total. Filenames may use only `a-z A-Z 0-9 _ + - . , =` (no spaces).
- **Text formatting:** single-spaced, 10–14pt, ≥ 1" margins.
- **Category:** primary **cs.LG** (Machine Learning); cross-list **stat.AP** (Applications) and
  optionally **cs.AI**.
- **Endorsement:** first-time submitters must be registered authors and **may need an endorsement** to
  post to a new category. An institutional email (e.g. `@sas.upenn.edu`) usually grants automatic
  endorsement; if not, an endorsement request goes to an established author in the category. **Start
  this early — it can take a few days.**
- **License:** authors grant arXiv an irrevocable distribution license (choose a license at submission;
  arXiv's default non-exclusive license is fine, or CC BY).
- **Preprint policy:** compatible with SSAC (non-double-blind). Standard practice is to post the
  extended version and cite it from the conference paper.

### Steps
1. Register / log in as an arXiv author; sort out endorsement if prompted.
2. Upload the LaTeX source as a `.zip` (main `.tex` + `.bib` + `figures/`).
3. Let arXiv compile; preview the PDF.
4. Fill metadata (title, authors, abstract, categories, license).
5. Submit; it appears after moderation (usually next business day).
